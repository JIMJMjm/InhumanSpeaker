# InhumanSpeaker

## Description
A samll script that can make you speak like inhuman beings.

## Usage
 - Install requirements.
 - Configure mode. 
   Do
   ```bash
   python main.py -mode *
   python main.py -model *
   ```
 - Use as normal `.py` scripts.
